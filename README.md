# Retail Sales Data – Exploratory Data Analysis

## Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to identify sales patterns, customer behaviour, and useful business insights.

## Tasks Performed

* Loaded and explored the dataset.
* Checked dataset shape, data types, missing values, and duplicates.
* Calculated descriptive statistics such as mean, median, mode, and standard deviation.
* Analysed monthly and quarterly sales trends.
* Analysed customer age groups and gender distribution.
* Identified top-selling products and revenue by product category.
* Created a correlation heatmap and additional visualizations.
* Derived key observations and business insights.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

The project uses a retail sales dataset containing information about transactions, customers, products, quantity, price, and total sales amount.

## Outcome

The analysis helped identify important sales trends, customer patterns, and product/category performance, providing actionable insights for better business decision-making.
